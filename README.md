# Сказочный Сад — игра «3 в ряд»

Небольшая браузерная игра match-3 в сказочном стиле с сюжетной прогрессией.

## Что есть

- **6 уровней** с целями: набрать счёт или собрать определённые фишки.
- **Ходы, счёт, комбо** — за длинные цепочки и каскады очков больше.
- **Звёзды (1–3)** за результат уровня.
- **Сюжет и карта** — проходи уровни, чтобы продвигаться по истории.
- **Сад Чудес** — трать звёзды на улучшения мира (цветы, ручей, дерево, фонтан, радуга); туман рассеивается по мере восстановления.
- **Сохранение** прогресса в `localStorage`.
- **Звуки** через Web Audio (без внешних файлов).

## Запуск

Это статический проект на ES-модулях, нужен локальный HTTP-сервер:

```bash
cd fairy-match3
python3 -m http.server 5175
```

Откройте http://localhost:5175

## Структура

```
fairy-match3/
  index.html        разметка экранов и модалок
  styles.css        стили
  src/
    data.js         типы фишек, уровни, улучшения, сюжет
    state.js        сохранение/загрузка, звёзды, улучшения
    engine.js       логика match-3: доска, свапы, матчи, каскады, счёт
    main.js         UI, рендер, ввод, экраны, модалки, звуки
```
